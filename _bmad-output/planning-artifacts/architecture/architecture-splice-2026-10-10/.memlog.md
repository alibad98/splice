- (direction) Fast path chosen by owner; audience = build agents + owner; spine only.
- (constraint) Inherited from PRD v0.3/tech-stack: Next.js dashboard, NestJS API, Postgres + Drizzle, Preact Web Component player w/ Shadow DOM, Turborepo; budgets NFR1 50KB/20KB; attribution FR13 cart-tagged line items; one merchant account per store; platform adapter (Q-07).
- (version) Verified via npm/web 2026-10-10: node 24 LTS, typescript 7.0, pnpm 12.11, turbo 2.11, next 16.4, react 19.3, @nestjs/core 12.1, drizzle-orm 0.45, drizzle-kit 0.31, drizzle-zod 0.8, postgres 18, preact 11.0, vite 8.3, zod 4.6, tanstack query 5.104, tanstack table 9.2, nuqs 2.10, react-hook-form 7.89, tailwind 4.3, shadcn 4.21, boneyard-js 1.10, pg-boss 12.37, pino 10.4, vitest 5.0, playwright 1.64, @salla.sa/twilight 2.14.590, @salla.sa/embedded-sdk 0.2.6.
- (decision) Paradigm: modular monolith (NestJS) with hexagonal ports/adapters at platform, media, CDN and storage edges; storefront read path is a precompiled per-store manifest on CDN (CQRS-lite); ingestion is append-only. Rejected microservices (team size, ops cost).
- (decision) One API deployable, two process roles (http, worker) from the same codebase; jobs via pg-boss on Postgres. Rejected BullMQ+Redis: extra infra and residency surface; revisit if job throughput saturates Postgres.
- (decision) Module data ownership: integration, catalog, content, media, publishing, analytics, attribution, billing, admin each own their tables; cross-module access only via the owner's service/events; no cross-owner writes.
- (decision) Tenant isolation: StoreScoped repository mandatory for tenant tables + Postgres RLS on app.store_id as safety net; admin uses separate DB role and audited path.
- (decision) Platform port CommercePlatform in api/platform; domain never imports Salla types; canonical entities carry (platform, external_id); PII stripped inside adapter. Player has its own StorefrontPlatform port wrapping salla.* SDK.
- (decision) Storefront reads: per-store manifest JSON compiled by publishing module and served via CDN keyed by store public id; recompiled on publish/unpublish, schedule boundary (scheduler job), linked product price/stock change, plan change, uninstall. Player never hits DB-backed read endpoints at render.
- (decision) Injection: Salla App Snippet is a tiny static stub (same for all stores) reading salla.config store.id/page and loading the versioned loader from Slips CDN; manual paste only as fallback. Runtime deps of player: preact only; shared packages type-only.
- (decision) Layout shift: overlays (full-screen viewer, floating bubble) mount on document.body; inline placements insert only when the manifest is eligible and the anchor is outside the viewport at insertion, else fall back to overlay/ring-in-existing-space. [ASSUMPTION until CLS test on 3 themes].
- (decision) Video: progressive MP4 renditions 480/720/1080 + poster; player picks by viewport and connection; no HLS in MVP (trigger: rebuffer/start-time SLO miss). Media processing behind MediaProcessor port; implementation (ffmpeg worker vs managed service) deferred to Q-05.
- (decision) Attribution: attribution module owns cart_adds (confirmed by Salla addItem promise) and attributed_lines; credit is a pure recompute over (cart adds, current order state) on every order event; idempotent replace per order. Primary join cart_id=checkout_id; fallback thank-you beacon. Money integer minor units, VAT excluded.
- (decision) Events: batched POST to ingestion endpoint; validate key+origin, rate limit, dedup by client event UUID; append to monthly-partitioned events_raw; rollups by scheduled jobs into daily tables; dashboard reads rollups only.
- (decision) Contracts: packages/contracts holds Zod schemas for every HTTP/JSON boundary (API DTOs, manifest, events); DB types (packages/db) never cross the API boundary; dashboard never touches DB.
- (decision) Auth: merchant via Salla embedded token introspection or Salla OAuth fallback -> Slips session httpOnly cookie issued by API; admin is /admin route group in dashboard with separate sign-in + API admin module guard + audit log.
- (decision) Webhooks: signature strategy (HMAC X-Salla-Signature) mandatory; inbox table idempotent by event id/hash; ordering by source updated_at; handlers run in worker.
- (decision) Billing: plan changes derived by comparing app.subscription.started with stored plan + subscriptions API reconciliation; no free plan; skip billing when store_type != live.
- (decision) Conventions: UUIDv7 ids; timestamptz UTC; store tz for schedules/display default Asia/Riyadh; money integer minor units + ISO code; errors RFC 9457 problem+json; logs pino JSON with store_id/request_id, no PII; i18n ar/en catalogs, CSS logical properties.
- (question) Q-05 data residency still blocks provider choice (DB region, object storage, CDN, media processing).
- (assumption) Inline-placement CLS approach and cart_id=checkout_id join are unverified until test store (G1, G4).
